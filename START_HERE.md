# Qamar Square — Start here

1. Extract this kit into the new Qamar Square project folder. Keep the `docs/` paths.
2. Open Claude Code in that folder and paste the contents of `Qamar_Square_Master_Prompt.md`. It starts with the water practice milestone.
3. Open `Qamar_Square_Build_Playbook.md` for the four-hour schedule, prompts for the remaining milestones, and the Tools, Design System and Skills libraries.
4. If you move to Codex or another coding model, open the same project folder, then use the resume prompt in the playbook.
5. Put team-owned artwork and any optional clips in `public/assets/` as they become available. The first playable milestone can start with placeholders.

The PRD and ADR contain the approved requirements and architecture. The original chat export documents how the decisions evolved. The science reference lists claims and primary sources to use in the game.
